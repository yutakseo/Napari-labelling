# 라벨러 모듈 구조

실행은 프로젝트 루트에서 `python main.py` 또는 기존 `start.bat` / `start.command`를 사용합니다. 명령행 인자도 그대로 지원합니다 (`python main.py --help`).

기본 입력 이미지, 초기 마스크, 출력 경로와 클래스·브러시·줌 설정은 **config.py**에서 수정합니다. 기본 경로는 프로젝트 루트를 기준으로 하므로 저장소를 다른 위치에 복제해도 그대로 동작합니다. 현재 기본 입력은 `input/노드1_전달용/20260911_232403/images/`, 수도 마스크는 같은 세션의 `masks/`이며, GT 작업 결과는 `output/20260911_232403/`에 생성됩니다.

예를 들어 프로젝트에 `input/video.mp4`를 넣었다면 다음처럼 실행할 수 있습니다.

```bash
python main.py input/video.mp4 --fps 10
```

`input/` 폴더에 이미지 파일만 넣은 경우에는 `python main.py`로 실행합니다. 다른 위치의 파일을 사용할 때도 절대 경로를 설정 파일에 저장할 필요 없이, 실행 시 상대 경로를 인자로 넘기면 됩니다.

수도 라벨을 GT로 후처리하려면 `--pseudo-mask`에 수도 마스크 파일 또는 폴더를 지정합니다. 입력 세션이 `.../20260911_232403/images/`라면 출력은 `output/20260911_232403/`에 생성되며, `images/`에는 RGB, `masks/`에는 보존된 원본 수도 마스크, `GT_mask/`에는 수작업 GT가 저장됩니다.

레이어는 아래부터 RGB → 주황색 수도 마스크(읽기 전용) → 청록색 GT(편집 가능) 순서입니다. 새 GT는 빈 마스크로 시작하므로 처음에는 주황색 수도 마스크만 보이며, 직접 칠한 부분만 청록색으로 나타납니다. 기존 `GT_mask/` 파일은 이어서 엽니다. 예전 버전에서 수도 마스크가 복사된 GT를 비우려면 `Start empty GT (backup current frame)` 버튼을 누르세요. 현재 GT를 `GT_mask_backups/<프레임>/`에 백업한 뒤 해당 프레임만 비웁니다.

단일 클래스 GT PNG는 배경 `0`, 전경 `255`로 저장되므로 일반 이미지 뷰어에서도 칠한 영역이 흰색으로 보입니다. Napari 내부 편집 값 `1`은 저장할 때 `255`로 변환하고, 다시 열 때 `1`로 복원합니다. 기존 `0/1` GT 파일도 세션을 다시 열면 같은 전경 영역을 유지하며 `0/255`로 변환됩니다. 다중 클래스 마스크는 클래스 ID를 그대로 저장합니다.

우측 상단에는 현재 프레임과 전체 프레임의 Dice가 표시됩니다. 전체값은 모든 프레임의 픽셀을 합산한 global Dice이며, 모든 비배경 클래스를 하나의 foreground로 취급합니다.

| 모듈 | 담당 기능 |
| --- | --- |
| `config.py` | 기본 경로, 클래스 정의, 편집 설정 |
| `cli.py` | 명령행 인자와 실행 경로 결정 |
| `classes.py` | 클래스 검증, 색상, 기존 클래스 메타데이터 복원 |
| `images.py` | 이미지 탐색과 RGB 로딩 |
| `masks.py` | 마스크 로딩·합성·미리보기, 영역 채우기 |
| `video.py` | 비디오 정보, FPS 선택, 프레임 추출 |
| `dataset.py` | 데이터셋 준비, 이미지/마스크 매칭, 메타데이터 저장 |
| `history.py` | 레이어별 undo/redo 스냅샷 |
| `input_events.py` | Qt 키보드·마우스·포커스 처리 |
| `types.py` | 콜백과 프레임 데이터 공통 타입 |
| `app.py` | napari UI, 편집 세션, 캐시·자동저장, 실행/종료 |

`main.py`는 `src.app.main()`을 호출하는 진입점입니다. UI 콜백은 세션 상태를 공유하므로 `app.py`에 함께 두었습니다. `CLASS_DEFINITIONS`는 `config.py`의 같은 딕셔너리를 공유하며, 실행 중 클래스 추가·복원이 모든 모듈에 반영됩니다.
